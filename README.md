# A股主线雷达 MVP

面向 A 股短中线研究的可追溯评分终端。当前版本已接入腾讯证券公开行情快照与前复权日线，不包含自动下单能力。

## 数据口径

- 三大指数、个股价格、涨跌幅及成交额：腾讯证券公开行情。
- 主题强弱：24 只固定观察池（6 个主题，每个主题 4 只）的统计，不是交易所官方行业指数。
- 最近交易日复盘：使用数据源返回的最近完整行情日，不用服务器当前时间伪装行情时间。
- 全A股涨跌家数由新浪财经公开行情分页统计；涨停、跌停、炸板、连板梯队和龙虎榜来自东方财富公开数据。
- 行业/概念主力资金流采用东方财富供应商定义口径，不解释为审计意义的真实资本流动。
- 腾讯行情约每 30 秒刷新，市场结构数据约每 5 分钟刷新；单一来源失败时保留最近成功缓存并逐源标记状态。
- 北向实时净买入、公募日频持仓、催化和融资融券未稳定接入，保持 `null/unavailable`，不会填零或猜测。
- 历史回看使用前复权近 5/20 日数据；这是当前固定观察池的回看，不冒充无未来函数的策略回测。

## 持仓、自选与次日观察

- “我的持仓”：选择股票、填写数量与可选成本价后添加，可计算参考市值和盈亏。
- “我的自选”：从当前 24 只固定观察池中选择并加入。
- “每日复盘”：点击“完成复盘并生成次日观察”，将强度前三主题的触发与失效条件导入“盘中预警”。
- 上述用户数据采用带版本号的浏览器本地存储，只保存在当前浏览器和当前设备；不会上传服务器，也不会连接券商或自动下单。
- “月度候选”按当前评分和近 20 日趋势动态排序，候选结果只用于研究，不代表买入许可。

## 双流分析

- “超短游资”：自动读取全市场涨跌、涨跌停/炸板、连板梯队、板块资金和龙虎榜；手工输入只用于补充知名席位、晋级率、溢价和题材分层。
- “价值投机”：自动读取当日板块资金与固定观察池 5/20 日趋势；产业景气、政策业绩、北向和公募证据仍可手工补充。
- 一次点击会生成两套独立报告和双流对照；缺失数据明确显示“未取得”，不会据此生成确定结论。
- 输入草稿与最近 20 次分析只保存在当前浏览器，可回看和复制报告。

## 本地运行

```bash
npm ci
npm run dev
```

- 前端开发地址：`http://127.0.0.1:5173`
- API 健康检查：`http://127.0.0.1:3001/api/health`

## 生产构建

```bash
npm run build
npm start
```

生产模式由 Express 同时提供 `dist/` 静态页面与 `/api/*` 接口，并支持 `/lifecycle` 等前端路由回退。

## Render 部署

仓库根目录包含 `render.yaml`。在 Render 创建 Blueprint 并连接本仓库即可；服务必须使用平台提供的 `PORT`，应用已绑定 `0.0.0.0`。

验收端点：

- `/`
- `/lifecycle`
- `/api/health`
- `/api/dashboard`

> 仅供研究，不构成投资建议。
