# A股主线雷达 MVP

面向 A 股短中线研究的可追溯评分终端。当前版本已接入腾讯证券公开行情快照与前复权日线，不包含自动下单能力。

## 数据口径

- 三大指数、个股价格、涨跌幅及成交额：腾讯证券公开行情。
- 主题强弱：24 只固定观察池（6 个主题，每个主题 4 只）的统计，不是交易所官方行业指数。
- 最近交易日复盘：使用数据源返回的最近完整行情日，不用服务器当前时间伪装行情时间。
- 全市场炸板率、催化、龙虎榜、融资融券尚未接入，接口保持 `null/unavailable`，不会填零或猜测。
- 服务端约每 30 秒刷新；刷新失败时保留上一份真实数据并标记 `stale`。

## 本地运行

```bash
npm ci
npm run dev
```

- 前端开发地址：`http://127.0.0.1:5173`
- API 健康检查：`http://127.0.0.1:3001/api/health`

## 生产构建

```bash
npm run build
npm start
```

生产模式由 Express 同时提供 `dist/` 静态页面与 `/api/*` 接口，并支持 `/lifecycle` 等前端路由回退。

## Render 部署

仓库根目录包含 `render.yaml`。在 Render 创建 Blueprint 并连接本仓库即可；服务必须使用平台提供的 `PORT`，应用已绑定 `0.0.0.0`。

验收端点：

- `/`
- `/lifecycle`
- `/api/health`
- `/api/dashboard`
